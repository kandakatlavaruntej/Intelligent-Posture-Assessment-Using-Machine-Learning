# My Contribution

This repository contains my implementation of the **Intelligent Posture Assessment Using Machine Learning** project.

## Responsibilities

I was responsible for the majority of the technical implementation, including:

- Designing the posture assessment pipeline.
- Developing the real-time posture detection system using Python, OpenCV, and MediaPipe.
- Implementing feature extraction from human pose landmarks.
- Training and evaluating the Random Forest classifier.
- Collecting and preparing the training dataset.
- Testing, debugging, and improving system performance.
- Integrating real-time visual feedback for posture correction.
- Preparing the GitHub repository and technical documentation.
