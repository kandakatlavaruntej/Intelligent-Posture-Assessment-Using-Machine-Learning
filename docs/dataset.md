# Dataset

## Overview

The posture classification model was trained using a custom dataset consisting of approximately **1,500 manually labelled sitting posture images** collected from multiple participants under different lighting conditions.

## Dataset Split

| Split | Percentage |
|--------|-----------:|
| Training | 80% |
| Testing | 20% |

## Data Collection

The dataset includes both **correct** and **incorrect** sitting postures captured from multiple individuals under varying lighting conditions.

## Availability

The original dataset is **not included** in this repository because it was collected as part of an academic research project and is no longer publicly available.
